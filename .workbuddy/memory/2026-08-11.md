# 2026-08-11 — Stripe 风格前端重构

## 概述
对 WizDev (Next.js 16.3 + React 19 + Tailwind CSS 4) 进行全面 Stripe 风格前端重构。

## 完成事项

### 1. 依赖管理
- 安装 `framer-motion` (动画库)
- 安装 `lucide-react` (SVG 图标库)
- 安装 `clsx` + `tailwind-merge` (之前缺失)
- 修复 `package.json` build 脚本: `next build` -> `next build --webpack` (Windows 平台 Turbopack 不支持)

### 2. 设计系统重写 (globals.css)
- 字体从 Inter 切换为 **Geist Sans + Geist Mono** (Next.js 内置)
- 重新定义 CSS 变量: 品牌色、语义色、表面色阶、边框不透明度等级
- 统一圆角比例 (6px-28px)、阴影层级
- 添加规范的缓动函数 `--ease-out-expo`
- 重构背景 mesh 效果，添加微妙的网格纹理
- 全新 `.card`, `.stat-card`, `.badge`, `.btn` 组件类
- 添加 `.skeleton` 加载态动画
- 支持 `prefers-reduced-motion` 无障碍
- 移除所有 emoji 使用

### 3. 组件重构 (全部替换 emoji 为 Lucide 图标)
- **layout.tsx**: Geist 字体配置，bg-mesh 背景层
- **Header**: Search/Bell/ChevronDown 图标，更精致的间距和透明度
- **Sidebar**: LayoutDashboard/GitPullRequest/Bug/Zap/BarChart3/Bot/Settings 等 SVG 图标，改进折叠态指示器
- **Footer**: 全新组件 — 品牌列 + 3列链接 + 底部状态栏（含系统状态指示灯）
- **StatsOverview**: GitPullRequest/Bug/Zap/Clock 图标，framer-motion stagger 入场动画
- **AIBriefing**: Bot/RefreshCw/ChevronUp/ChevronDown/Send 图标，优化标题排版
- **PullRequestList**: GitPullRequest/ArrowRight/MessageSquare 图标，彩色头像渐变
- **CIStatusPanel**: CheckCircle2/XCircle/Loader2 图标（含 spinning 动画）
- **ActivityChart**: 自定义 SVG 图标，framer-motion scaleY 柱状图动画
- **QuickActions**: FileText/BarChart3/ShieldAlert/Trash2 图标 + 自定义闪电 SVG

### 4. Dashboard 页面重排 (page.tsx)
- 引入 Footer，布局从 `h-screen` 改为 `min-h-[100dvh]`
- **后续**: 用户要求去掉 Footer，已从 page.tsx 移除 import 和 JSX（仪表盘不需要页脚）
- 间距从 `space-y-8` 调整为 `space-y-6`
- 使用 CSS 变量代替硬编码颜色

### 5. 构建验证
- TypeScript 类型检查通过
- Webpack 编译成功
- 静态页面生成正常
